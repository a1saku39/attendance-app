# 🚀 フィードバック機能追加 - デプロイ手順

## ⚠️ 重要：デプロイの更新が必要です！

新しい機能（要望・フィードバック投稿）を追加しました。
**Google Apps Scriptのデプロイを更新しないと、この機能は動作しません！**

## 📋 デプロイ手順（3分で完了）

### ステップ1: Apps Scriptエディタを開く

1. スプレッドシートを開く
2. メニューから「拡張機能」→「Apps Script」をクリック

### ステップ2: コードを確認

`Code.gs`を開いて、以下のコードが含まれているか確認してください：

```javascript
} else if (action === 'submitFeedback') { // フィードバック送信
   debugSheet.appendRow([new Date(), 'API実行: submitFeedback']);
   return submitFeedback(e);
}
```

※ もしコードが古い場合は、最新のコードを貼り付けて保存（Ctrl+S）してください。

### ステップ3: デプロイを更新 ⭐ 最重要！

#### 方法A: 既存デプロイの更新（推奨）

1. 右上の「**デプロイ**」ボタンをクリック
2. 「**デプロイを管理**」を選択
3. 現在のデプロイの右側にある ✏️（編集）アイコンをクリック
4. 「**バージョン**」→「**新バージョン**」を選択
5. 説明欄に `フィードバック機能追加` と入力
6. 「**デプロイ**」ボタンをクリック
7. 「完了」をクリック

#### 方法B: 新規デプロイ

1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 歯車アイコン⚙️→「**ウェブアプリ**」を選択
3. 設定：
   - 説明: `フィードバック機能追加`
   - 実行ユーザー: 自分
   - アクセス: 全員
4. 「**デプロイ**」をクリック
5. 新しいURLをコピーして、HTMLファイルの設定に保存

### ステップ4: 動作確認

1. アプリを開き、メニューから「💡 要望・フィードバック」を選択
2. フォームが表示されることを確認
3. テスト投稿を行ってみてください
   - カテゴリ: 質問・相談
   - タイトル: テスト投稿
   - 内容: これはテストです
4. 「送信する」をクリックし、成功メッセージが表示されればOK！
5. スプレッドシートに「フィードバック」シートが作成され、データが保存されているか確認

## ✅ 自動機能について

- **フィードバックシート**: 最初の投稿時に自動的に作成されます。手動で作成する必要はありません。
- **データ項目**: 日時、カテゴリ、タイトル、内容、優先度、名前、社員コード、ステータス、対応メモ

## ❌ エラーが出る場合

### 「送信に失敗しました」エラー

**原因**: デプロイが更新されていません

**解決方法**:
上記「ステップ3」を実行してデプロイを更新してください。

### 「通信エラーが発生しました」エラー

**原因**: GAS URLが設定されていないか間違っています

**解決方法**:
メイン画面の「設定（管理者用）」でGAS URLを確認し、正しいURLを設定してください。
