# 🚀 掲示板機能 - 今すぐデプロイしてください！

## ⚠️ 重要：必ずデプロイを更新してください

現在、Code.gsに掲示板機能のコードを追加しました。
**しかし、Google Apps Scriptのデプロイを更新しないと、この機能は使えません！**

## 📋 デプロイ手順（3分で完了）

### ステップ1: Apps Scriptエディタを開く

1. スプレッドシートを開く
2. メニューから「拡張機能」→「Apps Script」をクリック

### ステップ2: コードを確認

`Code.gs`を開いて、以下のコードが含まれているか確認：

```javascript
} else if (action === 'getBoardPosts') { // 掲示板投稿取得
   debugSheet.appendRow([new Date(), 'API実行: getBoardPosts']);
   return getBoardPosts();
} else if (action === 'postBoardMessage') { // 掲示板投稿作成
   debugSheet.appendRow([new Date(), 'API実行: postBoardMessage']);
   return postBoardMessage(e);
}
```

**含まれていない場合**:
- 最新の`Code.gs`の内容をコピー＆ペースト
- Ctrl+S で保存

### ステップ3: デプロイを更新 ⭐ 最重要！

#### 方法A: 既存デプロイの更新（推奨）

1. 右上の「**デプロイ**」ボタンをクリック
2. 「**デプロイを管理**」を選択
3. 現在のデプロイの右側にある ✏️（編集）アイコンをクリック
4. 「**バージョン**」→「**新バージョン**」を選択
5. 説明欄に `掲示板機能追加` と入力
6. 「**デプロイ**」ボタンをクリック
7. 「完了」をクリック

#### 方法B: 新規デプロイ

1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 歯車アイコン⚙️→「**ウェブアプリ**」を選択
3. 設定：
   - 説明: `掲示板機能追加`
   - 実行ユーザー: 自分
   - アクセス: 全員
4. 「**デプロイ**」をクリック
5. 新しいURLをコピーして、HTMLファイルの設定に保存

### ステップ4: 動作確認

1. 掲示板ページ（Board.html）を開く
2. 自動的にv3.3のリリース情報が表示されればOK！
3. 「管理者用：お知らせを投稿する」をクリック
4. テスト投稿を作成して「投稿する」
5. 成功メッセージが表示され、投稿一覧に追加されればOK！

## ❌ エラーが出る場合

### 「必要なパラメータが不足している」エラー

**原因**: デプロイが更新されていません

**解決方法**:
1. 上記「ステップ3」を**必ず**実行してください
2. ブラウザのキャッシュをクリア（Ctrl+Shift+Delete）
3. ページを強制再読み込み（Ctrl+F5）

### 「データの取得に失敗しました」エラー

**原因**: 
- デプロイが更新されていない
- GAS URLが設定されていない

**解決方法**:
1. デプロイを更新（ステップ3）
2. メイン画面の「設定（管理者用）」でGAS URLを確認
3. 必要に応じて最新のURLに更新して保存

### それでも解決しない場合

1. Apps Scriptエディタで「実行数」を確認
2. エラーログを確認
3. ブラウザのF12キー→Consoleタブでエラーを確認
