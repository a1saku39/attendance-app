# 勤怠管理アプリ v3.3 デプロイ手順

## バージョン情報
- **バージョン**: v3.3
- **リリース日**: 2026-02-12
- **主な変更点**: 日を跨いだ勤務時間計算の修正

## 更新内容の詳細

### 修正された問題
出勤時刻が `08:00`、退勤時刻が日を跨いで `00:40` になった場合、勤務時間がマイナスで表示される問題を修正しました。

**修正前**: `-7:20` と表示される
**修正後**: `16:40` と正しく表示される

### 技術的な変更
スプレッドシートの勤務時間計算式を以下のように変更しました：

```javascript
// 旧式
=IF(AND(F2<>"", H2<>""), TEXT(H2-F2, "[h]:mm"), "")

// 新式（日跨ぎ対応）
=IF(AND(F2<>"", H2<>""), TEXT(H2-F2 + IF(H2<F2, 1, 0), "[h]:mm"), "")
```

## デプロイ手順

### 1. Google Apps Script エディタを開く

1. スプレッドシートを開く
2. メニューから「拡張機能」→「Apps Script」を選択

### 2. コードの更新

1. `Code.gs` の内容を最新版に更新
   - バージョン情報が `v3.3` になっていることを確認
   - `getVersionInfo()` 関数が追加されていることを確認

2. 変更を保存（Ctrl+S または 💾 アイコン）

### 3. 新しいデプロイの作成

#### 方法A: 新規デプロイ（推奨）

1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 歯車アイコン⚙️をクリック→「ウェブアプリ」を選択
3. 以下の設定を確認：
   - **説明**: `v3.3 - 日跨ぎ勤務時間計算修正`
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 全員
4. 「デプロイ」をクリック
5. **新しいウェブアプリのURL**をコピー（後で使用）

#### 方法B: 既存デプロイの更新

1. 右上の「デプロイ」→「デプロイを管理」をクリック
2. 現在のデプロイの右側にある✏️（編集）アイコンをクリック
3. 「バージョン」→「新バージョン」を選択
4. 説明に `v3.3 - 日跨ぎ勤務時間計算修正` と入力
5. 「デプロイ」をクリック

### 4. HTMLファイルの更新（必要な場合）

Google Apps Scriptエディタで以下のHTMLファイルも最新版に更新してください：

- `index.html`（変更なし）
- `script.js`（バージョンチェック機能追加）
- その他のHTMLファイル（変更なし）

### 5. 動作確認

1. 勤怠アプリを開く（ブラウザでウェブアプリのURLにアクセス）
2. 画面上部に更新通知が表示されることを確認
   ```
   🎉 アプリが更新されました！ v3.3
   リリース日: 2026-02-12
   ・日を跨いだ勤務時間計算の修正（例：08:00出勤、翌00:40退勤 → 正しく16:40と表示）
   ・既存データは再打刻または手動修正が必要です
   ```
3. テスト打刻を実施して正常に動作することを確認

## トラブルシューティング

### 更新通知が表示されない場合

1. ブラウザのキャッシュをクリア（Ctrl+Shift+Delete）
2. ページを再読み込み（Ctrl+F5）
3. LocalStorageをクリア：
   - ブラウザの開発者ツール（F12）を開く
   - 「Application」→「Local Storage」→該当のURLを選択
   - `attendance_app_version` を削除
   - ページを再読み込み

### 既存データの修正方法

#### 方法1: 再打刻（推奨）
1. 該当の日付の出勤または退勤を再度打刻
2. 自動的に正しい計算式が適用される

#### 方法2: スプレッドシートで手動修正
1. スプレッドシートを開く
2. 該当の部署シート（例：`打刻_営業部`）を開く
3. I列（勤務時間）の正しい計算式をコピー
4. マイナス表示されている行のI列に貼り付け

正しい計算式の例：
```
=IF(AND(F2<>"", H2<>""), TEXT(H2-F2 + IF(H2<F2, 1, 0), "[h]:mm"), "")
```
